# Job Tab UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Redesign `/jobs` into a balanced-hub UI — overview strip (count chips + best-match callout) over a dense, fit-sorted list with inline HTMX apply/dismiss/expand.

**Architecture:** Presentation-only. Extend `web/routers/jobs.py` with HTMX fragment endpoints; split the page into Jinja partials so full-page and fragment responses share markup; add Mars-themed CSS. No changes to the scraper pipeline, the record store, or the application-tracker store — every field shown already exists on the enriched record.

**Tech Stack:** FastAPI + Jinja2 (server-rendered), HTMX (already loaded in `base.html`), plain CSS (`web/static/app.css`). Tests via Starlette `TestClient` in the existing plain-python runner `tests/test_job_scraper.py` (no pytest).

## Global Constraints

- Work in worktree `/Users/kayla.li/.superset/Agent-job-tab-ui` on branch `feature/job-tab-ui`.
- No new front-end libraries; HTMX only. No new Python deps.

- Reuse existing store APIs only: `jobstore.load_records()`, `jobstore.set_status(pid, status)`, `jobstore.STATUSES`, `tracker.add_application(company, role, url, status)`.
- Theme: jobs tab is Mars; accent `--accent` resolves to `#e07a4a` under `body[data-planet="mars"]`. The `/jobs` page must set `data-planet="mars"` (see Task 5).

```python
def _filtered_sorted(records, sort="fit", status="", company="", hide_ghost=False):
    rows = list(records)
    if status:
        rows = [r for r in rows if r.get("status") == status]
    if company:
        rows = [r for r in rows if r.get("company") == company]
    if hide_ghost:
        rows = [r for r in rows if not r.get("ghost")]
    keyfn = _SORTS.get(sort, _SORTS["fit"])
    rows.sort(key=keyfn, reverse=True)
    return rows


def _counts(records):
    counts = {s: 0 for s in jobstore.STATUSES}
    for r in records:
        if r.get("status") in counts:
            counts[r["status"]] += 1
    return counts


def _best_match(records):
    scored = [r for r in records
              if r.get("status") == "new" and r.get("fit_score") is not None]
    return max(scored, key=lambda r: r["fit_score"], default=None)


@router.get("/jobs/strip", response_class=HTMLResponse)
def jobs_strip(request: Request):
    records = list(jobstore.load_records().values())
    return templates.TemplateResponse(
        request, "partials/_jobs_strip.html",
        {"counts": _counts(records), "best": _best_match(records)},
    )
```

```python
def _row_response(request: Request, record: dict) -> HTMLResponse:
    return templates.TemplateResponse(
        request, "partials/_job_row.html", {"j": record},
        headers={"HX-Trigger": "jobsChanged"},
    )


@router.post("/jobs/apply", response_class=HTMLResponse)
async def apply_job(request: Request):
    form = await request.form()
    pid = str(form.get("pid", "")).strip()
    record = jobstore.load_records().get(pid)
    if record is None:
        return HTMLResponse("", headers={"HX-Trigger": "jobsChanged"})
    tracker.add_application(
        company=record.get("company", ""), role=record.get("title", ""),
        url=record.get("url", ""), status="applied",
    )
    updated = jobstore.set_status(pid, "applied") or record
    return _row_response(request, updated)


@router.post("/jobs/dismiss", response_class=HTMLResponse)
async def dismiss_job(request: Request):
    form = await request.form()
    pid = str(form.get("pid", "")).strip()
    jobstore.set_status(pid, "dismissed")
    return HTMLResponse("", headers={"HX-Trigger": "jobsChanged"})
```

Remove the now-unused `RedirectResponse` import if nothing else uses it (grep first: `grep -n RedirectResponse web/routers/jobs.py`).
